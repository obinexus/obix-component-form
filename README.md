## Verification

## Architecture role

`obix-component-form` is a **compatibility package**: it keeps an old name resolving and contains no logic — every export is the export of [`obix-core-component`](https://github.com/obinexus/obix-core-component). New code imports from `obix-core-component` (or from the umbrella `obix`).

The architecture of OBIX — the package families and which packages are public API — is indexed in the umbrella: [docs/architecture.md](https://github.com/obinexus/obix/blob/main/docs/architecture.md).
